Project Template v4.1.1 patch overlay

For an existing clean v4.1.0 project:
1. Back up your project.
2. Copy the contents of this patch overlay into the project root, preserving paths.
3. Review/merge README or status/config files if your project already contains active state.
4. Edit EXECUTE/MODEL_CONFIG.ini.
5. Run: python scripts/configure_models.py
6. Run: python scripts/validate_v4.py

For a new project, prefer the full "Project Template v4.1.1.zip" package instead of the overlay.
