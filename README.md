# Project Template v5.2.0

A deterministic, token-efficient AI development workflow with an exact human command protocol.

- Expensive models perform planning, architecture, diagnosis/recovery reasoning and independent evaluation.
- Low-cost Builders perform bounded immutable Tasks.
- `Workplan/` software owns state, authority, gates, resume, routing, reconciliation and verification.
- Humans start workflow execution only through exact Workplan commands; natural-language discussion never grants execution authority.

All AI surfaces bootstrap from **`Workplan/ENTRY_PROMPT.md`**. Normal user surfaces remain **External AI** for expensive reasoning and **VS Code Copilot Chat** with `@ExecutionManager` for bounded implementation.

Start with `Workplan/README.md`. Maintainers evolving this template must also read `Workplan/Objective_dev.md`.
