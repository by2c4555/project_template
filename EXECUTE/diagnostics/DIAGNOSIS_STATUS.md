# Diagnosis Status

```yaml
active_issue: none
diagnosis_version: none
diagnosis_status: NOT_ACTIVE
classification: none
root_cause_confirmed: false
repair_authorized: false
next_route: none
```

Allowed `diagnosis_status` values:

- `NOT_ACTIVE`
- `IN_PROGRESS`
- `ROOT_CAUSE_CONFIRMED`
- `BLOCKED`
- `COMPLETE`
