# Evaluation Status

```yaml
evaluation_version: none
evaluation_status: NOT_STARTED
evaluates_execution_version: none
result: none
blocking_findings: 0
diagnosis_required: false
completion_report: none
next_route: none
```

Allowed final results:

- `PASS`
- `PASS_WITH_FINDINGS`
- `DIAGNOSIS_REQUIRED`

`DIAGNOSIS_REQUIRED` does not decide whether code, plan, task, evaluation, or scope is wrong. Codex Diagnosis owns that classification.
